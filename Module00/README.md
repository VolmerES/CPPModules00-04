# C++ Module 00

## 📝 Overview

This module is designed to introduce the specificities of C++ compared to C. It covers the following concepts:

- Namespaces
- Classes & Member functions
- Stdio streams
- Initialization lists
- Static
- Const
- Formatting

## 📂 Exercises

### [Exercise 00: Megaphone](./ex00/)

**Goal:** Write a program that converts the string arguments into uppercase.

> Just like a megaphone, everything you say (type) comes out louder (uppercase).

### [Exercise 01: My Awesome PhoneBook](./ex01/)

**Goal:** Create a simple phonebook program.

> The program must behave like a crappy awesome phonebook software.
> You must implement two classes: `PhoneBook` and `Contact`.
> The program accepts commands:
>
> - `ADD`: store a new contact (limit 8).
> - `SEARCH`: display a specific contact.
> - `EXIT`: quit the program.

## 🛠️ Usage

To compile the exercises, go to the directory and run `make`:

```bash
cd ex00/
make
./megaphone "shhhhh... I think the students are asleep..."
```
