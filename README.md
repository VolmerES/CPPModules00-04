## 🗣️ About

This repository contains my solutions for the **C++ Modules 00 to 05** of the 42 Cursus. The goal of these modules is to introduce Object-Oriented Programming (OOP) using C++ 98. Starting from the basics of the language to more complex concepts like polymorphism and templates.

Each module is designed to tackle specific concepts of the C++ language.

## 📚 Modules Overview

### [Module 00: Basics of C++](./Module00/README.md)

**Focus:** Namespaces, Classes, Member functions, Stdio streams, Initialization lists, Static, Const.

> This module introduces the specificities of C++ compared to C, such as the standard input/output streams, namespaces, and the basic structure of classes.
>
> [Read more](./Module00/README.md)

---

### [Module 01: Memory Allocation & References](./Module01/README.md)

**Focus:** Memory allocation, Pointers to members, References, Switch statement.

> Focuses on dynamic memory allocation (`new`/`delete`), the difference between pointers and references, and the file stream interaction.
>
> [Read more](./Module01/README.md)

---

### [Module 02: Ad-hoc Polymorphism & Operator Overloading](./Module02/README.md)

**Focus:** Ad-hoc polymorphism, Operator overloading, Orthodox Canonical Class Form.

> Introduces the concept of polymorphism and how to overload operators to make user-defined classes behave like built-in types. It also imposes the Orthodox Canonical Form for classes.
>
> [Read more](./Module02/README.md)

---

### [Module 03: Inheritance](./Module03/README.md)

**Focus:** Inheritance.

> specific focus on Inheritance, allowing classes to derive properties and behaviors from other classes.
>
> [Read more](./Module03/README.md)

---

### [Module 04: Subtype Polymorphism & Abstract Classes](./Module04/README.md)

**Focus:** Subtype polymorphism, Abstract classes, Interfaces.

> Delves deeper into polymorphism using virtual functions and abstract classes to create interfaces.
>
> [Read more](./Module04/README.md)

---

### Module 05: Repetition and Exceptions

**Focus:** Exceptions, Try/Catch blocks.

> _Note: Module 05 is located in a separate repository structure in this workspace._
> Introduces C++ exceptions for error handling.

## 🛠️ Usage

Each exercise can be compiled individually. Navigate to the exercise directory and run `make`.

```bash
cd ModuleXX/exYY
make
./program_name
```
